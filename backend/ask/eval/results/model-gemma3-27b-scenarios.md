> AI-drafted prior authorization justifications were tested in two rounds (v1, Apr 2025; v2, Nov 2025) with the same utilization review nurse supervisor across both, which mattered for tracking whether fixes actually landed.

> Fix the outdated-diagnosis-code issue before any further piloting; this is a correctness bug, not a UX issue.
> Add inline source citations (chart entry + date) for every claim in the generated justification.
> Consider limiting initial pilot scope to 'straightforward' case types the nurses themselves can help define, deferring complex cases.

**[4] AI-Assisted Prior Authorization Drafting — Service Topology (v2)** — Map · `deliverable:service-topology/prior-auth-drafting-v2`
